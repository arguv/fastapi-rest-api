# AI Engineering API

A Python project for an AI engineering API. The current entry point is a minimal environment check; API endpoints are not implemented yet.

## Requirements

- Python 3
- No third-party dependencies are currently required.

## Run

From the project directory:

```bash
python3 main.py
```

Expected output:

```text
AI Engineering API - Environment Ready
```

## Optional virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
python main.py
```

On Windows, activate the environment with `.venv\Scripts\activate` instead.

## Project files

- `main.py` — application entry point.
- `.gitignore` — excludes local environments, secrets, caches, and generated files from Git.
